# Changelog

## 0.1.0

- First release: `.wasm` files open as WAT text with one fold per function, links from calls and exports to their function, find in all code and byte offsets.
- Overview of the module: sections with sizes, imports, exports, memories, tables, globals, custom sections, the name section, producers and features.
- WAT to WASM with errors and line numbers, WASM to WAT (Save as WAT, Open as WAT Text), and Validate, with no toolchain to install.
- WAT language support: syntax colors, outline, folding and errors while you type.
- Zovo Pro tools with 3 free tries each: size profiler, compare two builds, source mapping.
